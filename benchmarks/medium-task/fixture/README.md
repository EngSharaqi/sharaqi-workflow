# reading-list

A small reading-list library. No dependencies.

- `src/item.js` validates and normalises one item.
- `src/shelf.js` keeps items in memory with ids.
- `src/query.js` filters and sorts.
- `src/stats.js` totals and averages.
- `src/format.js` turns items into text.
- `src/csv.js` imports and exports CSV.
- `src/util.js` shared checks.
- `src/index.js` re-exports the public functions.

Run the tests with `npm test`.
