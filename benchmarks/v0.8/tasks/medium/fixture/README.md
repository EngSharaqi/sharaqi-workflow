# habits

A small habit tracker library. `npm test` runs the tests (Node 20+, no dependencies).

- `src/habit.js` — create and validate a habit
- `src/log.js` — check-ins per habit
- `src/streak.js` — current and longest streaks
- `src/stats.js` — completion rate over a date range
- `src/query.js` — filter and sort habits
- `src/format.js` — one-line text for a habit
- `src/csv.js` — CSV import and export
- `src/util.js` — calendar-day helpers
