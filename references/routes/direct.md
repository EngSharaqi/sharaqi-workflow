## Route: direct (non-coding)
Write the deliverable yourself, in the user's language: no plan, no snapshot, no review.
Executor `R8·haiku-low` only for long, well-specified text (delegation rules). Text meant to
be sent is prepared, never sent. Ask once if the input it needs is missing.
`research=searches>=N,sources>=M`: before writing, run at least N distinct web searches and
keep at least M distinct sources you actually read. Open every link you cite and drop any
that doesn't resolve. Cover each part the user asked for; when a figure (salary, demand)
isn't found, say so rather than estimate. Report: searches run, sources kept, links checked.
